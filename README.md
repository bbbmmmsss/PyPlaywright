# Shopify Demo Store Automation

## Project Overview
This project automates the end-to-end purchase flow for the Sauce Demo Shopify Store.

Website:
https://sauce-demo.myshopify.com

## Test Scenario

1. Launch Application
2. Login
3. Search Product
4. Add Product to Cart
5. Verify Product in Cart
6. Complete Checkout
7. Verify Order Success

## Technology Stack

- Python
- Playwright
- Pytest

## Project Structure

tests/
pages/
utils/

## Prerequisites

Python 3.10+

Install dependencies:

pip install -r requirements.txt

Install Playwright browsers:

playwright install

## Execute Test

test_saucedemo.py
